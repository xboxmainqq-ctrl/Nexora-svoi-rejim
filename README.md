# NEXORA — режим Minecraft Bedrock

Единый репозиторий плагинов режима NEXORA для Nukkit-MOT.

## Структура
- `plugins/NEXORA_MapBuilder` — строительство мира и постоянные координаты.
- Далее здесь будут добавляться остальные плагины режима (существа, классы/способности, бои, экономика и т.д.).

## Целевая серверная платформа
Nukkit-MOT. Известный идентификатор сборки сервера: `vgit-74e4b5c`.

> Важно: идентификатор commit не равен Maven-версии API. Перед публикацией JAR необходимо подтвердить точную зависимость и проверить сборку на целевой версии сервера.

## Состояние
MapBuilder находится на этапе начальной реализации. Наличие исходников в репозитории не означает, что JAR уже собран или протестирован на сервере.

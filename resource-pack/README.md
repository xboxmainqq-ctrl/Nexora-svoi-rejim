# NEXORA BEASTS — Bedrock Resource Pack

The pack now contains thirteen isolated custom companion prototypes:
- `nexora:beast_wolf` — custom model, rune texture, idle and walk animations
- `nexora:beast_fox` — custom pointed-ear model, bushy tail, orange/cream rune texture and animations
- `nexora:beast_cat` — custom slim model, upright tail, dark-violet/cyan texture and animations
- `nexora:beast_bee` — custom striped body, wings, stinger, golden texture and flight animation
- `nexora:beast_axolotl` — custom aquatic body, gills, fins, iridescent texture and swim animation
- `nexora:beast_horse` — custom body, mane, tail, rune markings and gallop animation
- `nexora:beast_panda` — custom rounded model, dark patches, cyan markings and walk animation
- `nexora:beast_polar_bear` — custom arctic model, icy texture and walk animation
- `nexora:beast_rabbit` — long-ear model, moonlit texture and hop animation
- `nexora:beast_ocelot` — sleek spotted model, golden coat and tail animation
- `nexora:beast_turtle` — shell, flippers and aquatic markings
- `nexora:beast_dolphin` — streamlined model, dorsal fin and swim animation
- `nexora:beast_parrot` — colorful model, crest, beak and wing animation

The Nukkit-MOT plugin registers matching network identifiers and reuses each
vanilla server entity implementation for movement and base behavior. Only
NEXORA companions use these custom identifiers; ordinary wild wolves, foxes
and cats keep their vanilla appearance.

## Rarity looks (10 unique creatures)

Each rarity has its own model and texture, generated by `rarity_looks.py`:
common grey wolf, uncommon moss turtle, rare crystal-blue wolf, epic violet
tiger, legendary golden lion, mythic pink crystal kitsune, ancient teal stag
with glowing antlers, divine white winged angel wolf (halo, horns), forbidden
abyss dragon-wolf (spikes, ember cracks) and absolute astral dragon-winged wolf.

They ride on the existing wolf / turtle / ocelot / fox / horse client entities:
the plugin sets the entity variant (`query.variant`) and the render controller
picks the matching geometry and texture. Variant 0 is the species look.
Switch with `rarity-looks` in the plugin `config.yml`.

## Gradient rarity lettering

`font/glyph_E2.png` holds anti-aliased gradient letters (real DejaVu Sans Bold
shapes, 1px outline) for the ten rarity words, each rarity with its own
three-stop gradient. Characters are `U+E200 + N`, counting letters over the ten
words in rarity order. Regenerate with `python3 resource-pack/tools/make_gradient_font.py`
(needs Pillow). The plugin uses them when `gradient-glyphs: true`.

## Build

Run `python3 resource-pack/build_pack.py`. It creates
`resource-pack/build/NEXORA_Beasts_RP.mcpack`.

GitHub Actions publishes the plugin JAR and resource pack as separate
artifacts. The resource-pack artifact is a ZIP containing the `.mcpack`;
extract the ZIP first, then import or install the contained pack.

## Server installation

The `.mcpack` is a Bedrock resource pack, not a plugin JAR. Install it through
the Nukkit-MOT resource-pack configuration and require clients to accept the
server pack. Keep the vanilla fallback until the custom entities have been
tested on the exact server and client versions.

These are still prototypes. The remaining species, rarity-specific
appearances/effects, and live in-game rendering/animation tests are not
complete yet.

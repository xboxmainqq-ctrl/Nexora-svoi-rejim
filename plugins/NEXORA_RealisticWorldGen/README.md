# NEXORA Realistic WorldGen

Отдельный Java 21 проект для Nukkit-MOT. Не зависит от LocalFastCore и не изменяет другие плагины.

## Возможности первой версии
- Отдельный генератор с именем `nexora`
- Базовый рельеф Nukkit-MOT сохраняет штатные пещеры, руды, биомы и структуры
- Дополнительное формирование широких горных областей, низин и речных коридоров
- Отдельная команда создания мира

## Сборка
Из этой папки:

```bash
mvn -U clean package
```

Готовый файл: `target/NEXORA-RealisticWorldGen-0.1.0.jar`

## Установка и использование
1. Скопировать JAR в папку `plugins` сервера.
2. Перезапустить сервер.
3. Выполнить от оператора:

```
/worldgen create my_nexora_world
/worldgen create my_nexora_world_2 123456789
```

Мир создаётся отдельно. Уже существующие миры не перегенерируются и не изменяются.

## Совместимость
Проект использует Java 21 и зависимость Nukkit-MOT `1.26.60-R1`, как соседний проект NEXORA_MapBuilder. Совместимость с конкретной сборкой сервера `vgit-74e4b5c` нужно подтвердить тестовой сборкой и запуском на этой сборке.

## Статус
Это начальная версия проекта. Перед использованием на основном сервере нужно собрать JAR и проверить генерацию на тестовом мире.
